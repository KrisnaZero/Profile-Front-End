## LogiTrack

**LogiTrack** adalah aplikasi web untuk **manajemen pengiriman** yang memudahkan pengguna dalam mencatat, memantau, dan mengekspor data pengiriman secara efisien. Aplikasi ini menggunakan **Firebase** untuk autentikasi dan penyimpanan data, serta menyediakan fitur ekspor ke Excel untuk laporan cepat.

---

## Fitur Utama

- **Login & Autentikasi** menggunakan Firebase Auth.
- **Input Data Pengiriman** dengan form yang mudah digunakan.
- **List Pengiriman** dalam bentuk tabel interaktif.
- **Ekspor Data ke Excel** (otomatis menghapus kolom foto nota dan aksi saat export).
- **Profil Aktif & Logout** di navbar.
- **Responsive Design** untuk tampilan mobile dan desktop.
- **Visualisasi Modern** dengan background dinamis dan animasi ringan.

---

## Teknologi yang Digunakan

- **Frontend**: HTML, CSS, JavaScript
- **Firebase**: Authentication, Firestore (opsional)
- **SheetJS (XLSX)**: Export data tabel ke Excel
- **Icon**: Remix Icon
